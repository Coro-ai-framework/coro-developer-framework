# Roadmap

Themes for the next ~90 days (no dates — priorities may shift based on design-partner feedback).

## 1. First-run experience

- README quick start that works on a fresh macOS/Linux machine without prior context
- Clear solo vs hybrid vs cloud setup paths in docs

## 2. Contributor-ready core

- CI that passes on forks without maintainer API keys
- Plugin authoring docs with `plugin-gitlab` as the reference
- Issue triage and CLA workflow stable for external PRs

## 3. Hosted Coro Cloud (commercial)

- Operable control plane deployment for design partners
- Team auth, webhooks, and runner connectivity hardened for multi-tenant use
- Paid tiers, SSO, and billing after design-partner validation (see launch plan)

## How to influence the roadmap

Open a [Discussion](https://github.com/Coro-ai-framework/coro-developer-framework/discussions) or feature issue. Large changes should follow the RFC process in [CONTRIBUTING.md](CONTRIBUTING.md).
